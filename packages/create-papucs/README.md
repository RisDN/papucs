# create-papucs

Create a ready-to-use Papucs Minecraft development project.

```bash
npm create papucs@latest my-network -- --accept-eula
```

The default template is branding-free and contains no bundled server JARs or
world data. `--accept-eula` explicitly accepts the Minecraft EULA.

See the [full documentation](https://github.com/RisDN/papucs#readme).
